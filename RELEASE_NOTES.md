# SimNIBS Headmodel & Target Add-ons v1.0.0-rc.1

First public release candidate. Based on internal Suite 1.80.2 distribution revision 4; Builder 1.80.2 and Cz Tool 2.4.2.

- DICOM conversion and CHARM workflow tools.
- Reviewed hybrid scalp repair, EEG recomputation and original/hybrid selection.
- MNI projection and Cz/BEAM/SPG scalp targeting outputs.
- English launchers, bilingual interface, portable path selection and GPL-3.0-only license.

Download the attached simnibs-headmodel-target-addons-v1.0.0-rc.1.zip. Extract it completely, install SimNIBS 4.6 and dcm2niix separately, and follow README.md. Use Start_Builder.vbs or Start_Cz_Tool.vbs.

This candidate awaits clean-machine Windows acceptance. A repaired localization scalp is not a reconstructed/validated volume FEM. No algorithm changes were made for public-release packaging. Third-party terms remain applicable.
