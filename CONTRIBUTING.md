# Contributing

Report bugs with public/internal versions, Windows and SimNIBS versions, steps, expected/actual behavior and redacted errors. Never attach clinical datasets or unredacted coordinates/logs to public issues.

Discuss algorithm changes separately from packaging changes. Include a relevant synthetic regression test and document coordinate systems/units when changing geometry. Record new dependencies and their sources. Preserve GPL and third-party notices. Contributions are submitted under the project's GPL-3.0-only terms unless a different applicable third-party license is explicitly retained and compatible.

Native Windows acceptance is documented in WINDOWS_ACCEPTANCE.md. Do not describe static checks as a completed Windows test or clinical validation.
